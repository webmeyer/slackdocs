====== KDE ======

 KDE Software Compilation (KDE SC) это [[slackware:desktop environment|окружение рабочего стола]] которое предоставляет пользователю огромный опыт графических приложений, а так же включает в себя большое количесвто программ, от браузера до редакторов фотографий. Это всё основано на наборе инструменторв Qt (Qt toolkit).

===== Установка =====

=== Новая установка ===
KDE входит в состав установочного DVD и является окружением по умолчанию, если вы выполняете полную установку.

 В процессе [[slackware:install|установки]], убедитесь, что Вы выбрали дискету с KDE пакетами (и при необходимости, KDEI для поддержки международных языков).
=== Добавление KDE в существующую установку ===
Если KDE не был выбран во время процесса установки, его можно установить позже с помощью программы ''slackpkg'' следующим образом:
<code>
darkstar~# slackpkg install kde
</code>
Все пакеты в ветке kde будут выбраны для установки. Вы можете отменить выбор отдельных пакетов, которые хотите пропустить во время установки, прежде чем нажать клавишу <key>ENTER</key> для начала самого процесса установки.

==== Выборочные пакеты ====
 Если Вы хотите использовать более новую версияю KDE, чем ту которая считается стабильной или ту которая находиться в текущей ветке (current branch), есть и такой вариант. AlienBob's [[http://alien.slackbook.org/ktown/ | ktown]] предоставляет всегда самую свежую версию коллекции программного обеспечения KDE готового для уставноки. Только помните, эти пакеты официально не поддерживаеться Slackware.


===== Конфигурирование =====

==== Визуальная унификация ====
 Приложения не от KDE будут вылядеть в базовом оформлении GTK, и такие программы не стилизированны под офрмление KDE.\\
В качестве обходного пути есть несколько пакетов призваных решить проблему унификации интерфеса между приложениями KDE и другими.\\

=== kde44-oxygen-molecule ===
 Может быть скачен с [[http://slackbuilds.org/repository/13.37/desktop/kde44-oxygen-molecule/|SBo]]. После установки, перейдите в Найстройки Системы -> Внешний вид приложений -> Цвета и выбирете Oxygen-Molecule_3.\\
Для не KDE-шных приложений, читайте эти настройки, создайте файл с именем  .gtkrc-2.0 в домашней директории и заполните его:
<code>
include "/usr/local/share/themes/kde44-oxygen-molecule/gtk-2.0/gtkrc"
style "user-font"
{
}
widget_class "*" style "user-font"
gtk-theme-name="kde44-oxygen-molecule"
gtk-font-name="fontname fontsize"   //  (for example: "Sans 10")
</code>
Иногда этот файл надо называть ".gtkrc-2.0-kde4", так что лучше иметь оба файла.
<code>
darkstar~# ln -s .gtkrc-2.0 .gtkrc-2.0-kde4
</code>
