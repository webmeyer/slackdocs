====== Неофициальные репозитории пакетов ======
  * 
  * **[[http://www.slackbuilds.org|slackbuilds.org]]** — этот сайт содержит присланные сообществом скрипты сборки, позволяющие легко создавать пакеты Slackware из исходного кода различных приложений.
  * **[[http://slackware.it/|slackware.it]]** — это репозиторий уже собранных (бинарных) пакетов, скомпилированных для различных языковых локалей.
  * **[[http://www.slackware.com/~alien/slackbuilds/|репозиторий alienBOB]]** — этот сайт содержит как готовые пакеты, так и связанные с ними скрипты сборки. Вы можете использовать его для скачивания пакетов напрямую или для получения стабильных скриптов с последующей сборкой под свои нужды.

<note>
Если вы хотите добавить другой репозиторий в этот список, пожалуйста, предложите его в списке рассылки slackdoc.
</note>
