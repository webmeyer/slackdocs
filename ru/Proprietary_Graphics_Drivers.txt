====== Проприетарные видеодрайверы ======

Графическая система X.Org X11 предоставляет множество драйверов, обеспечивающих как минимум 2D-ускорение видео для большинства видеокарт; однако, если система оснащена графическим процессором от AMD (ATI) или nVIDIA, проприетарные бинарные драйверы можно скачать с веб-сайтов этих поставщиков и установить в систему.

Цель этой статьи — описать различные методы установки и настройки этих проприетарных драйверов в Slackware.

===== Установка и настройка драйвера AMD (ATI) Catalyst =====

AMD прекращает поддержку старых карт (серии 4xxx и ниже) в текущей (12.6) и будущих версиях проприетарных драйверов, поэтому убедитесь, что ваша карта всё ещё поддерживается. Если она не поддерживается, то открытого драйвера xf86-video-ati должно быть достаточно, хотя он и работает немного медленнее проприетарной версии.
Примечание: этот драйвер не будет работать на Slackware 14.2, так как Catalyst поддерживает только Xorg 1.17 и ядро 3.19 (или нет?).

==== Скачивание ====

Обратите внимание, что установщик будет компилировать драйвер (fglrx), и для этого в системе должны быть установлены пакеты kernel-modules и kernel-source. Следующие шаги подходят как для графического (UI), так и для консольного (CLI) режима установщика.

==== Установка ====

Следующие инструкции описывают создание установочного пакета, подходящего для Slackware. Он генерируется установщиком автоматически и в большинстве случаев работает без проблем. Также существует метод «автоматической» установки.

Пакет драйверов Catalyst для Linux можно скачать по этой [[https://www.amd.com/en/support/download/drivers.html|ссылке]]. Файл подходит как для 32-битных, так и для 64-битных систем.

После скачивания распакуйте файл с помощью команды:
<code>
$ unzip amd-driver-installer-VERSION-x86.x86_64.zip
</code>

Далее получите привилегии root: 
<code>
$ su -
</code>

Переместитесь в каталог с файлом 'run' и запустите установщик:
<code>
# sh amd-driver-installer-VERSION-x86.x86_64.run
</code>

Установщик соберет данные о вашей системе и предложит либо автоматическую установку, либо создание пакета для конкретного дистрибутива. Выберите здесь создание пакета для конкретного дистрибутива, так как в дальнейшем им можно будет управлять с помощью инструментов управления пакетами Slackware.\\

Когда появится запрос на выбор дистрибутива, выберите «Detected OS: Slackware/Slackware».

После завершения сборки установщик сгенерирует установочный пакет в том же каталоге, где находится файл .run, и теперь вы можете выполнить:
<code>
# installpkg fglrx-VERSION-x86-1.tgz
</code>
  
Если были обнаружены ошибки во время установки вы можете увидеть их в''/usr/share/ati/fglrx-install.log''.

=== Настройка ====

Вам нужно будет перезагрузить систему для того, чтобы воспользоваться новыми драйверами. Прежде чем сделать это вам нужно отредактировать ''/etc/modprobe.d/blacklist.conf'' (или создать новый: ''/etc/modprobe.d/radeon_blacklist.conf'') и добавить следующие строки в файл:
<code>
blacklist radeon
blacklist radeonhd
</code>

Затем вы можете создать новый конфигурационный файл X.Org, запустив:
<code>
# aticonfig --initial -f
</code>

X.Org обычно не требует изменения файла ''/etc/X11/xorg.conf'', но в некоторых случаях (как правило, старые видеокарты) необходимо добавить следующую строку в разделе "Device":
<code>
Option "SWCursor" "true"
</code>  
Если ошибок не возникло и драйвер был успешно установлен, вам следует перезагрузить компьютер, чтобы задействовать новые драйверы.

=== Проверка ====

После перезагрузки, вы можете проверить работу драйвера, запустив:
<code>
$ fgl_glxgears
</code>  

Это должно запустить вращающиеся шестерёнки, которые двигаются плавно и без зависаний.

Можно также выполнить:
<code>
$ glxinfo
</code>

Взгляните на первые несколько строк вывода, чтобы проверить, включён ли DRI. Если он не включён, то вам придётся проделать ещё немного работы, поскольку функция создания пакетов, встроенная в установщик ATI, довольно старая (она появилась ещё до официального выхода 64-битной версии Slackware), и некоторые файлы необходимо переместить вручную, чтобы всё заработало на Slackware версии 14.1. Если ничего не помогло, можно воспользоваться опцией автоматической установки.

==== Автоматическое удаление ====

Если вы выбрали автоматическую установку и вам необходимо удалить драйверы, вы можете запустить установщик с дополнительным аргументом удаления, например так:
<code>
# sh amd-driver-installer-VERSION-x86.x86_64.run --uninstall
</code>

Или вызвать сценария удаления непосредственно:
<code>
# /usr/share/ati/amd-uninstall.sh
</code>

<note important>Независимо от того, как именно он был установлен, удаление драйвера fglrx «сломает» Mesa, так как некоторые файлы будут перемещены. Рекомендуется переустановить пакет mesa. Кроме того, если вы хотите вернуться к родным ядерным драйверам radeon/radeonhd, вам придется удалить строки блеклиста (blacklist), которые вы добавили ранее.</note>


===== Установка и настройка драйвера nVIDIA =====

==== Установка из SlackBuilds.org ====

Эдвард Кениг (Edward Koenig) поддерживает пакеты libvdpau, nvidia-driver и nvidia-kernel на сайте [[https://slackbuilds.org/|SlackBuilds.org]].

Для полноценной работы драйвера nVIDIA требуются все три пакета. Пакет nvidia-kernel собирает модуль ядра, пакет nvidia-driver собирает драйвер X.Org и содержит реализацию OpenGL, а также библиотеки COMPAT32 для использования в мультиархитектурных системах Slackware64 [[slackware:multilib|мультибиблиотечной]]. Пакет libvdpau является обязательной зависимостью для пакета nvidia-driver. 

==== Удаление модуля ''nouveau'' ====

Первым шагом при установке видеодрайвера является внесение nouveau в чёрный список (blacklist). Ошибка при выполнении этого шага может привести к сбою при запуске startx с сообщением «ERROR: could not insert 'nvidia': No such device».

Внесение драйвера nouveau в чёрный список осуществляется путём установки пакета xf86-video-nouveau-blacklist из каталога «extra» вашей версии Slackware. Это можно сделать с помощью установочного CD или DVD, скачав файл с зеркала Slackware или воспользовавшись утилитой slackpkg.

=== Установка пакета ===

Существуют два способа установки пакетов из SlackBuilds.org:
  * путем загрузки соответствующих сборочных сценариев из [[https://slackbuilds.org/result/?search=nvidia|SBo]], и сборки в соответствии с процедурой установки SlackBuild
  * использование утилиты [[https://sbopkg.org/|sbopkg]] которая автоматизирует загрузку исходных файлов и последовательную сборку/установку нескольких пакетов.

Как только пакеты были установлены с помощью инструкции, сопровождающие каждый SlackBuild, сервер X11 может быть запущен с полной поддержкой графического процессора. \\ Для того чтобы настроить X11 на автоматический запуск, смотрите "Запуск X11 с поддержкой графического процессора NVIDIA" в следующем разделе.

=== Загрузка соответствующего установщика драйвера nVIDIA ===

Первый шаг заключается в том, чтобы загрузить соответствующий драйвер с [[ https://www.nvidia.com/en-us/drivers/unix/ | вебсайта драйверов nVIDIA для Unix ]]. Для 64-разрядной версии Slackware (включая [[slackware:multilib|мультибиблиотечные]] системы) вам необходимо загрузить пакет драйвера "**Linux x86_64/AMD64/EM64T**", в то время как 32-разрядной версии Slackware необходим драйвер "**Linux x86/IA32**". Самый безопасный выбор для подбора правильной версии заключается в использовании "//Актуальной версии с долговременной поддержкой//" но в некоторых случаях (очень новая видеокарта или сопуствующие проблемы, которые вы пытаетесь решить), вы можете выбрать вместо этого "//Актуальную версию с кратковременной поддержкой//". \\ Устаревшие драйверы также доступны для старых видеокарт. При выборе драйвера, отобразится список совместимых графических процессоров. Как только вы определили нужный драйвер, необходимо принять условия лицензии, и сохранить файл в доступном месте. Перед запуском программы установки есть некоторые другие действия, которые должны быть приняты.

=== Деактивация модуля nouveau ===

В целом, графический процессор nVIDIA сразу же будет обнаружен и открытый графический драйвер "''nouveau''" активируется в системе. Это позволит использовать 3D-ускорение видео на многих картах. Модули ''nouveau'' и ''nvidia'' несовместимы; Таким образом, прежде чем приступить к установке модуля ''nvidia'', необходимо выгрузить ''nouveau'' и запретить его автоматическую загрузку.

Для этого должен быть создан файл в каталоге "''/etc/modprobe.d/''" и содержать текст
<code>
blacklist nouveau
options nouveau modeset=0
</code> 

и соответствующе назван, например, "''disable_nouveau.conf''"

Первая строка будет блокировать модуль ''nouveau'' от автоматической загрузки во время запуска. Модуль по-прежнему может быть загружен вручную пользователем или сервером X. Таким образом, вторая строка предотвратит modeset ядра, что позволяет выгружать модуль ''nouveau''.((ftp://download.nvidia.com/XFree86/Linux-x86_64/256.44/README/commonproblems.html)) 

<note>
Как упоминается в файле README для modprobe.d, монолитный файл чёрного списка модулей был разделён на файлы меньшего размера и перенесён в каталог /lib/modprobe.d/.
Тем не менее, файл с расширением .conf в каталоге /etc/modprobe.d/ будет иметь приоритет над файлом в /lib/modprobe.d/. Таким образом, этот способ является более надёжным для блокирования загрузки драйвера nouveau.
</note>

После вывода сообщения об ошибке, указывающего на несовместимость драйверов nouveau и проприетарных драйверов nVIDIA, более новые установщики nVIDIA запросят разрешение на создание .conf файла для внесения nouveau в чёрный список в каталоге /etc/modprobe.d/. Этот файл будет называться nvidia-installer-disable-nouveau.conf. По умолчанию содержимое этого файла будет следующим:
<code>
# generated by nvidia-installer
blacklist nouveau
options nouveau modeset=0
</code>

Затем установщик сообщит, что работа завершилась ошибкой, и потребует перезагрузить систему, чтобы изменения вступили в силу. После перезагрузки системы драйвер nouveau больше не будет загружаться, и установку бинарного драйвера можно будет продолжить.

В качестве альтернативы следует установить пакет ''xf86-video-nouveau-blacklist'' из каталога "''/extra''" на установочном носителе Slackware. После его установки систему необходимо перезагрузить, после чего можно будет продолжить установку драйвера.

=== Установка бинарного драйвера nVIDIA ===

Установка бинарного драйвера nVIDIA не может быть завершена, пока активна графическая система X11. \ \ По умолчанию Slackware загружается в текстовый терминал. В этом случае установщик nVIDIA можно просто запустить из консоли. Однако, если графическое окружение уже было запущено, из него необходимо выйти. Если оно было запущено с помощью команды "''startx''", закрыть графическое окружение можно, вылогинившись из системы или, и только в случае необходимости, нажав<key>Ctrl-Atl-Bksp</key>.

<note>Если используется графический менеджер входа в систему, такой как KDM, то обычный выход через меню или нажатие <key>Ctrl-Alt-Bksp</key> не сработает, так как графический менеджер входа перезапустится автоматически. \\ 

Лучший способ корректно завершить работу X-сервера — выйти из сессии, переключиться в текстовую консоль нажатием комбинации <key>Alt-F2</key>, войти в консоль от имени root и запустить: <code>telinit 3</code>

Другой метод возврата в консоль — грубый и поэтому не рекомендуемый, но эффективный при необходимости — это принудительная остановка/убийство процесса DM с последующим выходом из X-сервера нажатием клавиш <key>Ctrl-Atl-Bksp</key>. Например, процесс KDM можно убить, выполнив команду<code>killall -9 kdm</code> Опять же, этот способ следует использовать только в том случае, если другие методы не помогли.</note>

Как только X11 перестанет работать, установщик nVIDIA можно запустить от имени root. Для этого либо войдите в систему как root, либо выполните команду "''su -''", а затем запустите инсталлятор. В некоторых случаях полезно запускать установщик с использованием определенных параметров командной строки. Для получения дополнительной информации обратитесь к разделу «Параметры установщика nVIDIA» в конце этой секции.
<code>
$ su -
Password:
# sh /path/to/NVIDIA-Linux-ARCH-VERSION.run
</code>

Когда установщик запускается без каких-либо параметров командной строки и при отсутствии ошибок, процесс установки проходит следующим образом:

  * Установщик распакует себя и запустит ncurses-интерфейс. Первым шагом будет принятие условий лицензионного соглашения.
  * При установке модуля в систему, где не было предыдущей версии, установщик начнёт сборку модуля. Однако, если будет обнаружен ранее установленный драйвер nVIDIA, установщик запросит разрешение на его удаление в рамках текущей установки. Чтобы продолжить установку, необходимо дать разрешение на удаление предыдущей версии.
  * После сборки модуля на системах x86_64 установщик предложит установить 32-битные библиотеки совместимости OpenGL от nVIDIA. Эти 32-битные библиотеки совместимости понадобятся вам только в том случае, если ваша система Slackware является 64-битной с поддержкой //[[slackware:multilib|multilib]]//.
  * Затем, в случае наличия предыдущей версии, установщик произведёт деинсталляцию старого модуля.
  * Как только будет подтверждено отсутствие конфликтующих файлов X-сервера и (если был выбран этот параметр) библиотек OpenGL, модуль будет установлен.
  * После этого программа предложит использовать утилиту nvidia-xconfig для изменения файла xorg.conf, чтобы отразить смену видеодрайверов. Эта утилита зачастую работает корректно, но потенциально может изменить и другие значения в xorg.conf. Тем не менее, она создаёт резервную копию оригинального файла по пути "''/etc/X11/xorg.conf.nvidia-xconfig-original''".
  * Всплывающее окно подтвердит, что установка драйвера завершена и прошла успешно, после чего программа закроется и вернёт вас в консоль.

Теперь модуль nvidia должен быть установлен для текущего запущенного ядра.

Вы должны самостоятельно создать конфигурационный файл X.Org, который загружает бинарный драйвер Nvidia, если вы решили //не// разрешать утилите nvidia-xconfig изменять файл xorg.conf вашего компьютера. X.Org в Slackware поддерживает отдельные файлы «*.conf» в каталоге /etc/X11/xorg.conf.d. Любой файл с расширением .conf будет подключён вместе с главным файлом /etc/X11/xorg.conf.

Вы можете создать, например, файл с именем /etc/X11/xorg.conf.d/10-nvidia.conf со следующим содержимым:
<code>
Section "Device"
    Identifier  "Device0"
    Driver  "nvidia"
    VendorName "Nvidia Corporation"
    BoardName ""
EndSection
</code> 

Без этого определения вы не получите поддержку аппаратного ускорения графического процессора Nvidia! X.Org откатится к режиму VESA, так как драйвер nouveau был внесён в чёрный список. //Ядро не сможет автоматически обнаружить бинарный драйвер, в отличие от драйвера nouveau//.

===== Запуск X11 с поддержкой графического процессора nvidia =====

Всё, что теперь осталось сделать, — это запустить сервер X.org. Это можно реализовать, настроив Slackware для запуска на 4-м уровне инициализации (runlevel 4), что позволит автоматически загружать графический менеджер входа в систему, такой как KDM или XDM, при загрузке компьютера. Если вы хотите этого, то вам нужно отредактировать файл “/etc/inittab” и изменить строку:

<code>
id:3:initdefault:
</code>

на:

<code>
id:4:initdefault:
</code>

В противном случае вы можете войти в учётную запись пользователя и выполнить команду "''startx''" для запуска X-сессии.

<note>По умолчанию startx запускает тот оконный менеджер, который был выбран во время установки. Чтобы изменить это поведение, можно отредактировать файл ".xinitrc" в домашнем каталоге пользователя, указав там запуск другого оконного менеджера. \ В качестве альтернативы, оконный менеджер по умолчанию можно изменить индивидуально для каждого пользователя с помощью команды "''xwmconfig''", выбрав один из доступных оконных менеджеров.</note>

== Параметры установщика nVIDIA ==

Установщик nVIDIA имеет множество параметров, доступных системному администратору, список которых можно получить, запустив установщик с флагом -A:

<code>
# sh ./NVIDIA-Linux-ARCH-VERSION.run -A
</code>

Некоторые из наиболее часто используемых параметров:

  * ''-a, %%--%%accept-license'' : пропустить экран с лицензионным соглашением nVIDIA. Использование этого флага означает автоматическое принятие лицензии.
  * ''%%--%%update'' : проверить наличие обновлённой версии драйвера на веб-сайте nVIDIA; если обновление существует, автоматически скачать и установить новую версию.
  * ''%%--%%uninstall'' : удалить драйвер nVIDIA и другие ранее установленные файлы.
  * ''-q, %%--%%no-questions'' : автоматически использовать ответы по умолчанию на все вопросы. Примечание: этот параметр не означает автоматическое принятие лицензии.
  * ''-s, %%--%%silent'' : запустить бинарный установщик без графического ncurses-интерфейса, автоматически принять лицензию и использовать ответы по умолчанию для всех вопросов.
