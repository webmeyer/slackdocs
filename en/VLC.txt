====== VLC ======

VLC is a media player that can play almost any media format and act as a streaming server. It is an open source project led by VideoLan.

The following [[slackware:slackbuild_scripts|slackbuilds]] by AlienBob are available to install VLC:

  * Codec-free version: http://www.slackware.com/~alien/slackbuilds/vlc/
  * With codecs version: http://slackware.org.uk/people/alien/restricted_slackbuilds/vlc/
